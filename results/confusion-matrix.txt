READING IT HONESTLY
  Among the labelled fields the gate withheld 2 values: 2 correct and 0 incorrect,
  while 2 wrong values passed straight through it. On this subset the gate is
  therefore all cost and no benefit. That is not a flaw in the implementation but a
  property of what it tests: LOCATABILITY, not correctness. A wrong value copied
  verbatim from the document passes; a right value paraphrased by the model fails.
  Because the labels were fixed independently of the gate, this is a non-circular
  measurement, it is the strongest available answer to Reviewer #1, and it happens
  to be unfavourable.

  The gate earns its place on the UNLABELLED majority, where the ungated hybrid
  leaves 15.4 % of surfaced values unlocatable and the gated one leaves none. Those
  removals cannot be scored here because those fields carry no labels, which is
  precisely the gap the human audit instrument was built to close.

  It also argues that the strict gate is the wrong operating point: the relaxed
  variant recovers all 2 withheld-but-correct values at no cost in ungroundedness. The obstacle to
  adopting it as canonical is that it was tuned in-sample, not that it performs worse.
